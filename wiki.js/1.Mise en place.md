Installation de Debian en terminal sur le shuttle :
- lancer l'installation de Debian en Ui ou en installation classique.
- Suivre les étapes jusqu'au choix de l'environnement de bureau.
- Désélectionner tout excepté Server ssh et "standard system utilities"
- Finaliser l'installation et laisser le système redémarrer.

Une fois que Debian a redémarré :
- Se connecter au compte précédemment créé
- passé en compte root avec la commande : su -
- Vérifier les mises à jour et les lancer si nécessaire :
(pas besoin de précéder de "sudo")
```
apt update && apt upgrade
```

Connexion en ssh pour mettre en place les prochaines étapes :
- Toujours en "su -" sur la machine : check de l'ip avec : 
  ```
  ip a
  ```
  
- En suite :  
  ```
  Systemctl enable --now ssh
  ```
  Check :
  ```
  systemctl status sshd
  ``` 
- Se connecter en SSH via l'ip de la machine et refaire la commande "su -" pour passer en root via SSH
- Changer son ip (si elle doit être dans un range particulier) :
  - "nano /etc/network/interfaces"
  - modifier les informations de la carte réseau : 
```
[The primary network interface] 
    auto enp0s31f6 
    iface enp0s31f6 inet static
    address 192.168.X.X/XX
    gateway 192.168.X.1
    dns-nameservers 1.1.1.1 8.8.8.8 (ou DNS spécifiques)
```
